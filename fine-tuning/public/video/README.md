# Video slots

Drop `<name>.mp4` here and the matching `<VideoSlot name="...">` picks it up on
next load — no code change. See `../../VIDEOS.md` for the five slots and the
prompts to generate them.

MP4 / H.264, 16:9, 1280x720, **no audio**, 6-12 s, under ~2 MB.

Files here are git-ignored; only this README is tracked.
